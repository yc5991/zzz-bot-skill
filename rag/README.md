## 检索

```bash
python tools/query.py "妮可和法厄同是什么关系" -k 5
python tools/query.py "零号空洞是什么" --kind world -k 5
python tools/query.py "以骸" --kind character -k 3
python tools/query.py "第三季结局" --season 第三季 -k 3
python tools/query.py "邦布" --json
```

- `--kind`：`plot` 剧情 / `character` 角色卡 / `world` 世界观，默认全部
- `--season`：`第一季` / `第二季` / `第二季尾音` / `第三季`（句中提到季名会自动带上）
- 剧情结果带 `集号 + 时间戳`，可直接回原片定位

## 重建

需要项目里的 `参考wiki/`、`_work/bili-transcribe/raw_fixed/`、`_work/rag/glossary.json`：

```bash
python tools/build_kb.py
```

## 部署到云电脑

只查不改的话，把整个 `rag/` 拷过去即可：

```bash
pip install jieba
python tools/query.py "零号空洞"
```

不需要 GPU、不需要模型、不需要联网；`query.py` 只依赖 Python 3.10+ 和 jieba。

## 限制

- 检索是 **BM25 关键词**，不是语义向量：问“谁背叛了谁”这类纯语义问题召回一般；
  问人名/地名/术语/剧情关键词很准。要语义检索可以再加 bge-small-zh（约 95 MB）做混合召回。
- 剧情正文来自本地 ASR，专有名词仍可能有残余同音误差；引用原台词前建议对时间戳看画面。
- 角色卡是 wiki 清洗稿，技能数值已剔除；需要技能细节回 `参考wiki/角色/`。
